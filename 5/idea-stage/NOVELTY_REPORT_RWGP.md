# Novelty Check Report — Idea 1: Residual-Weighted Global Pooling (RWGP)

## Proposed Method
Use the per-correspondence epipolar residual (already computed by `batch_episym` in every stage) as soft weights for global average/max pooling inside MB-FFN blocks. High-residual correspondences (outliers) receive near-zero weight, preventing them from contaminating the global context feature.

## Core Claims

### Claim 1: Using geometric residuals as pooling weights in FFN-style blocks
**Novelty: HIGH**

**Closest Prior Work**:
- **ACNe** (Sun et al., CVPR 2020): Uses *learned* attentive weights for **Context Normalization** (feature normalization, not pooling). The weights are generated by a small MLP from the features themselves, not from geometric residuals.
- **Context Normalization** (Yi et al., 2018): Non-parametric normalization over all correspondences; no weighting at all.
- **SE blocks / attention pooling** (Hu et al., 2018; various follow-ups): Use global pooling to generate channel attention weights, but do not use geometric residuals as spatial weights for pooling.

**Key Difference**: RWGP uses **domain-specific geometric confidence** (epipolar residual) as spatial pooling weights, whereas ACNe uses **learned feature-based attention** for normalization. RWGP is parameter-free and directly encodes geometric plausibility.

### Claim 2: Application to MB-FFN / feed-forward blocks in correspondence networks
**Novelty: HIGH**

**Search Results**: No prior work applies residual-weighted pooling specifically to FFN-style blocks in two-view correspondence networks. MB-FFN itself (from MGCA-Net / Transformer literature) has only been used with vanilla global pooling.

**Key Difference**: The combination of "geometric residual weighting" + "FFN global pooling" + "correspondence learning" is unique.

### Claim 3: No new parameters; reuses existing residual tensor
**Novelty: MEDIUM**

This is a methodological choice rather than a technical novelty, but it makes the method minimal and easily integrable.

|-------|------|-------|---------|----------------|

## Overall Novelty Assessment

- **Score: 8/10**
- **Recommendation: PROCEED**
- **Key differentiator**: The first method to use epipolar residuals as soft spatial weights for global pooling inside FFN blocks, specifically for two-view correspondence outlier rejection. The combination of "geometric residual" + "pooling weight" + "correspondence FFN" is novel.
- **Risk**: A reviewer might argue that ACNe already solved "outlier-aware global context" and that RWGP is just "applying the same insight to pooling." Counter: ACNe uses learned attention for **normalization**, which is a different operation from **pooling**, and its weights are feature-derived rather than geometry-derived.
- **Suggested Positioning**: Frame RWGP as "extending the ACNe principle from normalization to pooling, with a critical twist: using geometry-derived residuals instead of learned feature attention, making the mechanism parameter-free and directly tied to epipolar consistency."
